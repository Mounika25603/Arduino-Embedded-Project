# Arduino-Embedded-Project
Embeddded systems project using arduino and thinkercad
1.Automatic street Light system
Description
This project automatically switches ON the street light when the surrounding environment becomes dark and switches OFF when sufficient light is available.
### Components Used:
Arduino UNO
LDR Sensor
10K Ohm Resistor
LED
220 Ohm Resistor
Breadboard
Jumper Wires
### Working principle:
The LDR sensor detects the surrounding light intenstity.Arduino reads the analog value through the A0 pin.
*If the light intensity is low, the LED turns ON.
*If the light intensity is high, the LED turns OFF.
